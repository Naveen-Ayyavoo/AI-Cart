## 1. Defects Resolved & Additional Audit Fixes Applied

### A. Seven Original User-Reported UX Defects
1. **Sample Demo Workflow (`contracts/views.py`, `templates/home.html`)**: All sample scenario chips route through the unified Purchase Contract Review -> Confirm -> Discovery workflow; editing a demo prompt clears hidden `#scenario-key-input` so edited text is never bypassed as an unedited demo fixture.
2. **Stuck Home CTA (`templates/base.html`, `templates/home.html`)**: Shared `window.AICartUI` `pageshow` listener (`event.persisted` + DOM state reset) restores the submit button label/enabled state, resets validation, and clears `#tc-global-live-status` across browser Back navigation and abort/cancel actions.
3. **Missing Images in Expanded Candidates (`catalog/client.py`, `catalog/views.py`, `catalog/templates/catalog/_product_card.html`, `catalog/templates/catalog/product_list.html`)**: Normalized heterogeneous Channel3 payloads (`image`, `image_url`, nested `image` dicts, `images[]` preferring `is_main_image=True`, `image_urls`, `raw_evidence`), validated `http`/`https` schemes, extracted shared `_product_card.html` with `loading="lazy"` and inline SVG fallback (`tcHandleImgError`), and prioritized `ELIGIBLE -> UNKNOWN -> INELIGIBLE` before top-3 slicing.
4. **Loading Feedback & Recovery (`templates/base.html` + 8 flow templates)**: Added `#tc-workflow-progress`, `#tc-global-live-status` (`aria-live="polite"`), `[data-loading-link]` / `[data-loading-form]` double-submit locking, `prefers-reduced-motion` support, and a 15-second slow-response recovery banner.
5. **Post-Confirmation Budget Revision (`contracts/models.py`, `contracts/forms.py`, `contracts/urls.py`, `contracts/views.py`, `orders/models.py`, `catalog/views.py`, `policies/views.py`)**: Added `"Increase budget"` workflow on Discovery & Policy Evaluation creating Draft `v(N+1)`, superseding `vN` atomically while keeping `vN.max_budget` immutable, voiding unconsumed approvals (`VOIDED`), superseding open proposals (`SUPERSEDED`), and requiring explicit re-confirmation without authorizing payment.
6. **Interactive Optional Clarifications (`contracts/clarifications.py`, `contracts/views.py`, `contracts/templates/contracts/review.html`)**: Replaced static `"material, fit, size"` text with category-specific interactive fields (`8` product profiles + `general`), `"These details are optional. You can skip them and continue."` guidance, strict-requirement toggle checkboxes, and server validation.
7. **Product-Specific Edit Search Criteria (`contracts/clarifications.py`, `contracts/templates/contracts/review.html`)**: Populated placeholders, hints, and attribute suggestions dynamically from category metadata via `json_script`, eliminating electronics defaults from non-electronics contracts and associating every input with `<label for>`.
